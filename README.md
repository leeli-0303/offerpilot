# OfferPilot — AI 求职管理助手

> 面向应届生的智能求职管家：统一管理岗位、简历、投递进度，用 AI 做匹配分析和策略复盘。

---

## 1. 为什么做 OfferPilot？

应届生秋招/春招期间平均投递 30-80 家公司，同时维护 2-4 版简历，需要跟踪每一家的投递进度、面试安排和反馈结果。大多数人用 Excel 或飞书表格管理，但存在几个核心问题：

| 痛点 | 现状 | 后果 |
|------|------|------|
| **JD 录入成本高** | 逐字段手工填写公司、岗位、要求 | 录 10 个岗位就放弃维护 |
| **匹配判断靠直觉** | 看一眼 JD 就决定投不投 | 匹配度低、浪费投递机会 |
| **进度容易遗漏** | 投完就忘了，面试通知来了才想起来 | 错过跟进窗口、面试准备仓促 |
| **复盘缺乏依据** | 求职结束只知道结果，不清楚过程哪里出问题 | 下次还是同样的坑 |

**OfferPilot 的产品假设**：如果把求职当作一个可管理的项目，用 AI 承担信息提取、匹配分析和进度提醒的脏活，应届生的求职效率和决策质量能显著提升。

## 2. 目标用户

- **主要用户**：正在参加秋招/春招的应届毕业生（本科、硕士）
- **次要用户**：有实习需求的在校生、毕业 1-2 年内的求职者
- **用户画像**：同时投递多家公司多个岗位，需要维护多版简历，对投递节点和面试安排有管理需求

## 3. 核心价值

**一句话：从"海投碰运气"到"数据驱动的精准求职"。**

- **信息聚合**：一个界面管理所有岗位、简历版本和投递记录，告别多平台切换
- **AI 匹配分析**：岗位要求 vs 简历内容 → 量化匹配度 + 差距分析 + 优化建议，帮你优先投递把握最大的岗位
- **进度可视化**：看板 + 漏斗图展示求职全流程，一眼看清哪些卡住了、哪些该跟进了
- **策略复盘**：每周自动生成求职周报，统计投递转化、方向反馈和简历表现，持续优化策略

## 4. MVP 功能矩阵

### 4.1 岗位管理（Job Tracker）
- 手动创建/编辑岗位，粘贴 JD 原文自动解析结构化信息
- **规则解析**：正则 + 关键词提取（公司、技能、方向、优先级）
- **AI 解析**：LLM 提取结构化字段，支持自然语言 JD
- 岗位卡片/看板视图，按公司、方向、优先级筛选

### 4.2 简历管理（Resume Vault）
- 支持多版简历（后端-中文 / 后端-英文 / 算法-中文 等）
- 每版简历关联目标方向、关键词和项目亮点
- 简历字段摘要展示，为匹配分析提供结构化输入

### 4.3 投递追踪（Application Tracker）
- 9 种状态流转：待投递 → 已投递 → 笔试/测评 → 一面 → 二面 → HR面 → Offer/拒绝/放弃
- 记录投递日期、渠道（内推/官网/BOSS直聘）、使用简历版本
- 看板视图按状态分组，一键切换状态，支持备注

### 4.4 AI 匹配分析（Match Lab）
- 岗位与简历的**多维度匹配评分**（技能 45%、标签 20%、方向 20%、项目 15%）
- **规则版**：加权打分 + 模糊技能匹配（30+ 别名映射）+ 风险扣分
- **AI 版**：LLM 综合评估，输出匹配点、缺失项、优化建议和推荐行动
- 匹配结果可导出为 Markdown 文件

### 4.5 面试准备（Interview Prep）
- 基于岗位技能和方向自动生成面试准备包
- **规则版**：23 个技能 → 面试题模板映射，8 类行为问题，8 类反问问题
- **AI 版**：LLM 结合简历实际项目生成 STAR 回答技巧和个性化面试题
- 包含：岗位摘要、重点经历、可能被问的问题、建议反问、准备贴士

### 4.6 下一步行动建议（AI Next Action）
- 根据投递状态和已过天数自动生成下一步建议
- 待投递 → 结合匹配度给出投递/观望/放弃建议
- 已投递 → 按天数提醒跟进（3天/5天/7天阈值）
- 面试中 → 根据轮次给出侧重点（技术基础 vs 系统设计）
- 每条建议标注紧急程度（高/中/低）

### 4.7 求职周报（Weekly Review）
- **规则版**：自动统计投递数、面试数、方向分布、简历使用，生成策略建议
- **AI 版**：基于统计摘要（不传原始数据），LLM 生成策略分析和下周计划
- 包含：核心指标卡片、方向分布图、投递漏斗、本周总结、发现问题、下周行动
- 支持导出 Markdown，便于分享或存档

### 4.8 数据看板（Dashboard）
- 关键指标卡片（投递总数、面试中、Offer 数、拒绝数）
- 近期投递事件时间线
- 按公司/状态/方向快速过滤

## 6. AI 工作流设计

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   用户输入    │ →  │   AI 处理层   │ →  │   结果展示    │
│  JD文本/简历  │    │ LLM + 规则   │    │ 结构化+可视化 │
└──────────────┘    └──────┬───────┘    └──────────────┘
                           │
                    ┌──────▼───────┐
                    │  失败?        │
                    │  fallback    │
                    │  规则引擎     │
                    └──────────────┘
```

### AI 功能清单

| 功能 | 触发方式 | 输入 | AI 输出 | 降级策略 |
|------|---------|------|---------|----------|
| **JD 解析** | 用户粘贴 JD 点击解析 | 原始 JD 文本 | 结构化字段（技能、标签、方向、优先级） | 规则正则提取 |
| **匹配分析** | 用户选择岗位+简历点击分析 | 岗位要求 + 简历关键词/亮点 | 匹配评分 + 匹配点 + 缺失项 + 优化建议 | 规则加权打分 |
| **面试准备** | 用户选择投递记录点击生成 | 岗位信息 + 简历内容 | 个性化问题 + STAR 技巧 + 反问建议 | 模板匹配 |
| **求职周报** | 用户点击生成 | 统计摘要（不传原始数据） | 策略分析 + 问题诊断 + 下周计划 | 规则策略引擎 |

### AI 设计决策

- **输入最小化**：周报只传统计摘要不传原始数据，避免 token 浪费同时减少幻觉
- **LLM 不做数据计算**：统计/评分由规则引擎计算，LLM 只做语义分析和策略建议
- **Mock 模式优先**：默认不调 API，开发调试不消耗 token；设置环境变量即可切换到真实 API
- **双模式可对比**：每个 AI 功能都有规则版对照，方便评估 AI 增量和调试

## 7. 技术栈

| 层级 | 技术选型 | 选型理由 |
|------|---------|----------|
| **UI 框架** | Streamlit | Python 原生、极低前端成本、适合 MVP 快速验证 |
| **数据持久化** | JSON 文件（`data/store.json`） | 零配置、适合单用户场景、迁移成本低 |
| **AI 接口** | OpenAI-compatible Chat Completions | 厂商无关，可接入 OpenAI / DeepSeek / 通义千问 / 智谱等 |
| **AI 降级** | 规则引擎（Regex + 词库 + 加权评分） | 不依赖 API 也能正常工作 |
| **数据模型** | Python Dataclass | 类型安全、序列化简单、与 JSON 互转方便 |
| **图表** | Streamlit 原生图表 + Pandas | 无需额外图表库 |
| **导出** | Markdown 生成器 | 通用格式，可被 Notion/Obsidian/飞书导入 |

## 8. 本地运行

### 环境要求
- Python 3.10+
- pip

### 安装步骤

```bash
# 1. 克隆项目
git clone <repo-url>
cd offerpilot

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动应用（Mock 模式，无需 API Key）
streamlit run app.py

# 4. 浏览器访问
# http://localhost:8501
```

### 切换到真实 AI 模式

#### 方式一：.env 文件（推荐）

```bash
# 1. 复制配置模板
cp .env.example .env

# 2. 编辑 .env，填入真实值
# LLM_MODE=real
# LLM_API_KEY=your-api-key
# LLM_BASE_URL=https://api.deepseek.com/v1
# LLM_MODEL_NAME=deepseek-chat

# 3. 启动应用（python-dotenv 自动加载 .env）
streamlit run app.py
```

#### 方式二：环境变量

```bash
# Linux / macOS
export LLM_MODE=real
export LLM_API_KEY="your-api-key"
export LLM_BASE_URL="https://api.deepseek.com/v1"
export LLM_MODEL_NAME="deepseek-chat"

# Windows PowerShell
$env:LLM_MODE="real"
$env:LLM_API_KEY="your-api-key"
$env:LLM_BASE_URL="https://api.deepseek.com/v1"
$env:LLM_MODEL_NAME="deepseek-chat"

streamlit run app.py
```

#### 测试连接

```bash
# 验证配置和 API 连接
python scripts/test_llm_connection.py
```

#### 支持的 API 提供商

任何兼容 OpenAI Chat Completions 接口的提供商均可，包括但不限于：

| 提供商 | `LLM_BASE_URL` | `LLM_MODEL_NAME` |
|--------|----------------|-------------------|
| **智谱 GLM（推荐）** | `https://open.bigmodel.cn/api/paas/v4/` | `glm-4.7-flash` |

> **免费模型推荐**：GLM-4.7-Flash 完全免费（需在 [bigmodel.cn](https://bigmodel.cn) 实名认证），上下文窗口 200K，最大输出 128K tokens，并发限制 1 QPS，适合个人开发使用。

## 10. 与在线表格的差异

做这个产品之前，我调研了周围同学的做法：大部分人用飞书多维表格或 Excel 管理求职。OfferPilot 和它们不是同类工具，解决的是不同层次的问题。

| 维度 | 在线表格 | OfferPilot |
|------|---------|------------|
| **JD 录入** | 逐字段手工填写 | 粘贴原文，AI 自动提取结构化信息 |
| **简历关联** | 手动标注或超链接 | 结构化关联，一键触发匹配分析 |
| **匹配判断** | 肉眼对比 JD 要求和简历 | AI 量化评分 + 差距分析 + 具体修改建议 |
| **进度可视化** | 需手动建图表 | 自动看板 + 漏斗图，状态流转一键操作 |
| **行动提醒** | 靠自己记得去看 | AI 根据时间/状态/匹配度主动建议下一步 |
| **面试准备** | 去牛客/知乎搜面经 | 基于岗位技能和简历项目自动生成准备包 |
| **策略复盘** | 把表格数据人工汇总成周报 | 自动统计 + AI 策略分析 + 下周计划 |
| **协作** | 天然支持多人编辑 | MVP 仅单用户（后续可扩展） |

**核心差异**：表格是数据库，记录"发生了什么"；OfferPilot 是教练，告诉你"接下来该做什么"。

## 11. 后续规划

### Phase 2 — 数据驱动增强
- **投递转化漏斗**：按渠道/方向/简历版本的转化率分析
- **面试题库积累**：用户反馈面试题 → 题库沉淀 → 更精准的 prep 建议
- **薪资对比**：Offer 条件结构化对比（base、股票、签字费、公积金比例）
- **数据导入**：支持从 BOSS 直聘/牛客导出现有投递记录

### Phase 3 — 智能化升级
- **智能投递建议**：根据匹配度 + 截止日期 + 竞争激烈度给出优先级排序
- **面试模拟**：基于岗位和简历自动生成模拟面试对话
- **个性化学习路径**：根据缺失技能推荐学习资源（课程、文章、项目）
- **求职节奏规划**：根据目标行业的时间线自动规划投递节奏（提前批→正式批→补录）

### Phase 4 — 生态扩展
- **多设备同步**：移动端适配，支持微信小程序查看
- **协作功能**：求职小组互相分享面经和岗位信息
- **匿名社区**：Offer 薪资匿名分享 + 公司评价聚合
- **企业端对接**：ATS 系统集成，自动同步投递状态

## 12. 设计理念

- **AI 是手段，不是目的**：每个 AI 功能都有清晰的用户价值定义和降级方案，不为 AI 而 AI
- **尊重用户控制权**：所有 AI 调用由用户主动触发，AI 建议标记清晰来源，不做黑盒决策
- **渐进式复杂度**：默认 Mock 模式零门槛上手，需要时一键切换到真实 AI
- **数据可携带**：JSON 文件存储 + Markdown 导出，不锁定用户数据
